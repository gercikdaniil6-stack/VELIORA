# VELIORA — отчёт о фирменных материалах и интеграции

Дата: 18.11.2026 · Версия приложения: 1.0.0

## 1. Исходные условия

- В папке `Desktop\VELIORA` не было кода, и на компьютере не нашлось проекта с названием GLASSLINK или VELIORA. По решению заказчика приложение **VELIORA App создано с нуля** (Tauri 2 + React 19 + TypeScript), бренд встроен сразу.
- Поиск старых названий (`GLASSLINK`, `glass link`) по проекту: **0 совпадений**. Переименовывать было нечего.

## 2. Работа с референсом

| Что было в референсе | Что сделано |
|---|---|
| V из двух полупрозрачных лент: голубая слева, лавандовая справа | Сохранено. Ленты перестроены как точные кривые Безье на сетке 512 |
| Светлое перекрытие лент внизу | Линза задаётся как **точное пересечение** лент (clip-path), а не отдельной фигурой. Края больше не расходятся |
| Сгиб на левой ленте (вторая версия референса) | Сохранён как светлая внутренняя грань, мягче и без резких переходов |
| Асимметрия: левая лента шире, скруглённое основание | Сохранена |
| Надпись: тонкий геометрический гротеск, широкая разрядка | Начерчена вручную (V E L I O R A), с оптической компенсацией: O с выносом за линию, кривые на 6 % толще, отдельный кернинг для пар L–I и R–A |
| Растровые блики и случайные градиенты | Убраны. Градиенты подобраны под палитру; отдельные версии для светлого и тёмного фона |

Итерации знака (черновики сравнивались визуально):
1. Ленты по контуру референса: левая лента вышла слишком тяжёлой, линза — узким серпом.
2. Ленты сужены, линза стала заметнее, но правая лента «вздувалась» внутрь.
3. **Финал:** нижняя часть лавандовой ленты заходит под синюю, и пересечение даёт крупную каплю-линзу, как в референсе. Под ней остаётся синий изгиб основания. Монохром: левая лента идёт поверх правой, между ними зазор.

## 4. Интеграция в приложение

| Место | Реализация |
|---|---|
| Компонент логотипа | `src/brand/BrandLogo.tsx` + реестр `src/brand/brand.ts`. Единственное место, где упоминаются файлы логотипа. Размер задаётся по видимому рисунку, охранное поле компенсируется по `manifest.json` |
| Заголовок окна | `TitleBar`: своя рамка без системной, `BrandLogo variant="inline"` |
| Боковая навигация | `Sidebar`: стеклянный активный пункт с меткой в фирменном градиенте, мини-статус подключения |
| Главный экран | `Overview`: статус в фирменном градиенте; маршрут «устройство → знак → сервер», где две линии сходятся в знаке (идея логотипа) |
| Экран настроек | `Settings`: окно и трей, «Уменьшить прозрачность», знак |
| О приложении | `About`: мастер-логотип, версия из Tauri |
| Стартовый экран | `Splash`: знак проявляется из размытия, надпись сжимается, 1,25 с; можно отключить |
| Системный трей | `lib.rs`: иконка, подсказка «VELIORA App — подключено · Сервер», меню «Открыть / Подключить–Отключить / Выход», левый клик открывает окно |
| Иконка приложения | `icon.ico` в exe, окне и на панели задач |
| Установщик | NSIS: иконка, боковая и верхняя картинки, издатель VELIORA, русский язык, установка для текущего пользователя |
| Метаданные | `productName: VELIORA App`, exe `VELIORA.exe`, идентификатор `app.veliora.desktop`, заголовок окна «VELIORA App», описание и copyright в `tauri.conf.json`, `Cargo.toml`, `package.json` |

## 6. Skills и инструменты

| Инструмент | Как использован |
|---|---|
| Skill `built-in-browser` (Anthropic, встроенный) | загружен, им проверялся интерфейс в браузерной панели |
| `@resvg/resvg-js` (npm, официальный пакет resvg) | рендер SVG → PNG/ICO/BMP в генераторе |
| Pillow (уже был установлен) | независимая проверка ICO, PNG и BMP, сборка листа превью |
| Tauri CLI 2 / NSIS | сборка exe и установщика |
| Chrome DevTools Protocol (встроен в WebView2) | скриншоты окна приложения без доступа к экрану |

Сторонние Skills **не искались и не устанавливались**: всё нужное (рендер векторов, ICO, сборка Tauri) закрыли проверенные пакеты из списка выше, а ставить непроверенные установочные скрипты задача запрещала. Skill `frontend-design` был доступен локально, но не загружался: визуальные решения опираются на референс заказчика и дизайн-систему из `docs/DESIGN_SYSTEM.md`. Новые npm-зависимости: `@resvg/resvg-js` (только для разработки) и `@fontsource-variable/manrope` (шрифт интерфейса).
