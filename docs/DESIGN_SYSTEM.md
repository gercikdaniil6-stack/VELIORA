# VELIORA — дизайн-система (Liquid Glass)

Токены: `src/styles/tokens.css`. Компоненты: `src/styles/app.css`.

## Принципы

1. **Свет, а не неон.** Два мягких источника света на фоне (голубой сверху слева, лавандовый снизу справа) повторяют ленты логотипа. Свечение — только у активных состояний.
2. **Стекло со смыслом.** Полупрозрачны только поверхности, лежащие над фоном (карточки, панели, модальные окна). Внутри стекла — плотная типографика без лишних эффектов.
3. **Один акцент.** Фирменный градиент (Ice → Electric → Lavender) используется для главного действия экрана и статуса «Подключено». Больше нигде.
4. **Спокойное движение.** Переходы 140 / 260 / 520 мс на кривой `cubic-bezier(0.22, 1, 0.36, 1)`; при `prefers-reduced-motion` анимации отключаются.

## Стекло

```css
background: var(--glass-fill), var(--glass-tint);  /* белый 6,6 → 2,6 % поверх navy 42 % */
backdrop-filter: blur(28px) saturate(150%);
border: 1px solid rgba(255,255,255,.085);
box-shadow: inset 0 1px 0 rgba(255,255,255,.09), 0 8px 24px rgba(4,7,14,.22);
```

Плюс «зеркальная кромка» (`.glass::before`): светлая граница сверху, растворяющаяся к середине. Вариант `.glass--strong` — для главной карточки экрана и модальных окон.

Настройка **«Уменьшить прозрачность»** заменяет стекло плотными поверхностями (`data-transparency="reduced"`).

## Типографика

Шрифт интерфейса — **Manrope Variable** (геометрический гротеск с кириллицей, по характеру близок к надписи логотипа). Моноширинный — Cascadia Mono / Consolas для адресов и портов.

## BrandLogo — правила

```tsx
<BrandLogo variant="symbol" size="md" />        // знак, размер = высота самой ленты
<BrandLogo variant="inline" size={20} />        // знак + надпись в хроме интерфейса
<BrandLogo variant="lockup" size={92} />        // мастер-файл связки (О приложении)
<BrandLogo variant="wordmark" size={18} />      // только надпись, размер = высота прописной
```

Размеры: `xs 16 · sm 20 · md 28 · lg 48 · xl 96`. Тон: `dark` (по умолчанию), `light`, `mono-white`, `mono-black`. Размер всегда задаётся по видимому рисунку, а не по рамке файла: компонент компенсирует встроенное охранное поле SVG по `manifest.json`.
