# Менеджер Zapret

## Правила и выбор стратегии

Каталог и «Мои сайты» расширяют доменные списки стратегии Zapret. Правило действует на домен и поддомены, если они предусмотрены логикой сопоставления winws. Исключения сборки остаются в силе. Для Telegram в каталоге указаны веб-домены. Прокси для клиента Telegram управляется на отдельной странице.

Конфигурация сайтов хранится в пользовательском config.json. При подготовке запуска Rust формирует list-veliora-managed.txt внутри защищённой папки Zapret и добавляет его в те же секции, которые уже принимают list-general-user.txt. Пользовательские IP-списки и списки Flowseal сохраняются. Правило с привязкой к стратегии действует, когда выбрана указанная стратегия. Одновременно работает одна стратегия. Если активный набор доменов меняется, приложение перезапускает свой Zapret. При ошибке оно пытается восстановить предыдущий запуск. 

## Добавление по ссылке в 2.2.9

В каталоге откройте «Добавить сайт», вставьте ссылку и нажмите «Добавить и настроить». Отдельный редактор ранее сохранённого сайта сохраняет его название и привязку к стратегии. Импорт и экспорт списков TXT в интерфейсе отсутствуют.

VELIORA сопоставляет адрес с готовыми профилями по основным и дополнительным доменам. Поддомены учитываются на границе DNS-метки. Повторный ввод включает существующее правило или готовый профиль. Ранее сохранённая строка сайта сохраняет свои параметры.

VELIORA сохраняет текущую стратегию, когда она поддерживает нужный список. Если стратегия ещё не выбрана, используется успешный результат теста для установленной версии или совместимая стандартная конфигурация из сборки. При изменении активного списка действует прежний механизм перезапуска и восстановления. Если Zapret выключен, пользователь может включить его после сохранения. Если текущие настройки несовместимы, приложение сообщает о проблеме.

Кнопка проверки делает прямой HTTPS-запрос к главной странице сайта с проверкой TLS. Она не передаёт путь, параметры, cookie или данные авторизации из исходной ссылки, не следует перенаправлениям и исключает частные IP-адреса. Успешный ответ подтверждает доступность главной страницы в момент проверки. Открытие страниц по отдельным путям и доступность всех функций сайта требуют проверки в браузере.

## Версии

Список стабильных версий и даты взяты из [релизов Flowseal](https://github.com/Flowseal/zapret-discord-youtube/releases). Если у архива отсутствует SHA-256 от GitHub, приложение блокирует загрузку. ZIP сначала проверяется, затем распаковывается в отдельную папку. Аргументы текущей стратегии проверяются до замены файлов. Хеш кэшированного архива проверяется заново при переключении. При ошибке запуска после переключения приложение пытается вернуть прежнюю сборку. Кэш архивов находится в защищённой папке ProgramData, рядом с рабочей копией Zapret.

VELIORA использует отдельный механизм обновления с подписью Tauri. Подробнее в [описании процесса выпуска](APP_UPDATES.md).

## Статистика

Счётчик добавляет время только в состоянии Zapret «Запущен». Он не считает пакеты или посещения сайтов. Хранятся время, число запусков, число успешных пунктов системной диагностики и агрегаты по дням UTC. После аварийного выключения теряется время с последней точки сохранения. «Сервисы в стратегии» показывает число включённых карточек при запущенном Zapret. Этот показатель не измеряет доступность сервисов.

## Контрольная проверка на отдельной Windows

1. Открыть чистую установку и проверить Obsidian. Выбрать другую тему, перезапустить приложение и проверить сохранение.
2. Добавить в «Мои сайты» две тестовые ссылки по одной. Повторить добавление и проверить, что первая запись используется повторно. Проверить редактирование, выключение и удаление.
3. Выбрать независимую тестовую машину без других экземпляров winws. Запустить стратегию, включить правило для тестового домена и проверить доступность конкретного сайта. Выключить правило и проверить, что базовое поведение не меняется.
4. Установить совместимую версию из списка, переключиться на локальную и повторить переключение без сети. На тестовом профиле проверить, что запуск с несовместимой стратегией сохраняет рабочую версию.
5. Проверить Telegram, YouTube и Discord отдельно. Голос и трансляцию Discord проверять со вторым участником. Повторно открыть VELIORA и сверить накопленное время и события.

## Референс

[Slipgate](https://github.com/tenstepsbeforedecay/Slipgate) использован для изучения компоновки главной и сценариев выбора версии. Реализация VELIORA использует собственные компоненты React и команды Tauri. Код Slipgate под GPL-3.0 не переносился.

Проверены категории, отсутствие Discord и YouTube в каталоге, переключатель сервиса, добавление домена из URL, удаление дубликатов, выключение и удаление сайта. Проверены сохранение настроек после полного перезапуска, главный экран, статистика и раздел обновлений. Импорт и экспорт TXT проверены в WebView2, набор нормализованных доменов совпал.
- Проверено последовательное переключение всех 14 тем. Ошибка отменённой анимации при быстрых переключениях исправлена, повторная проверка прошла без исключений JavaScript.
- `winws.exe --dry-run` в изолированной копии принял правила с добавленным доменным списком для 22 из 22 встроенных стратегий. Конфигурация YouTube из `list-google.txt` сохранена.

- На рабочем компьютере уже запущен другой winws. Полный тест переключения с активным драйвером, сетевые пробы по каждому сервису и установка NSIS поверх рабочей VELIORA требуют отдельной Windows без конфликтующего компонента.
