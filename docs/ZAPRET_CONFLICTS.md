# Конфликты Zapret в VELIORA 2.2.10

## Как работает диагностика

При запуске и перед включением приложение проверяет известные исполняемые файлы Zapret и других инструментов WinDivert. Процесс с совпадающим именем без загруженной WinDivert.dll игнорируется, если Windows дала прочитать список модулей. Если доступ к процессу ограничен, VELIORA показывает, что подтверждение получить не удалось. В диалоге доступны путь, PID и результат локальной проверки Authenticode, когда эти сведения доступны. Проверка конфликта выполняется по событию, без постоянного опроса.

Имя или родительский процесс помогают объяснить конфликт. Разрешение на остановку появляется только для отдельной службы Windows, у которой совпадают PID и путь исполняемого файла. Служба должна принимать штатную команду остановки. Windows перепроверяется непосредственно перед запросом. Учитывается зарегистрированная строка запуска и учётная запись службы. Для обычного процесса сторонней программы гарантированного общего интерфейса остановки нет.

## Разрешения

«Остановить службу и включить Zapret» отправляет штатный запрос диспетчеру служб Windows. Право применяется только к той службе, которую показал диалог. Для сохранённого разрешения совпадают её имя, строка запуска, учётная запись и SHA-256 исполняемого файла. Разрешения хранятся в защищённой папке VELIORA и отзываются через настройки. Если обнаружен хотя бы один процесс без сохранённого разрешения, автоматическое завершение всей группы не выполняется. Для диалога с явным разрешением VELIORA останавливает только выбранную службу.

Системные драйверы и регистрации WinDivert не удаляются. Собственный процесс ограничен Windows Job Object, поэтому его завершение освобождает удерживаемые им ресурсы. При сообщении о занятом фильтре VELIORA ждёт и делает одну повторную попытку. Если собственный Zapret неожиданно завершится уже после успешного запуска, автоматическое восстановление разрешает одну попытку до следующего ручного включения. Успешный запуск подтверждает сообщение winws об инициализации захвата. Доступность отдельных сервисов проверяется отдельно через диагностику.

Если Windows удерживает файлы драйвера при обслуживании, может потребоваться перезагрузка. У VELIORA нет подтверждения прав на остановку общего драйвера, используемого неизвестной программой.

## Проверено

- Нативная сборка без повышения прав увидела работающий сторонний winws и состояние службы WinDivert. Чужой процесс продолжил работать.
- В отдельном тесте исполняемый файл с именем winws.exe, который не загрузил WinDivert.dll, был проигнорирован.
- Проверены единственный экземпляр тестовой VELIORA, диалог для неподтверждённого процесса, отказ при недействительном разрешении и отсутствие ошибок WebView2.
- Два отдельных теста проверили однозначность пути службы и совпадение сохранённого разрешения с её идентификатором. Эти тесты не отправляют команды диспетчеру служб.

Для проверки на отдельной Windows с правами администратора нужны выделенная тестовая служба WinDivert, проверка отказа и сохранённого согласия, аварийное завершение собственного winws и повторный сбой. Рабочие сторонние службы на этом компьютере не останавливались.
