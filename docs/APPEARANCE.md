# VELIORA 2.1 — оформление, темы и движение

## Архитектура

| Слой | Файл | Что делает |
|---|---|---|
| Библиотека тем | `src/theme/themes.ts` | 12 тем (7 светлых, 5 тёмных) + построитель Custom. Тема — набор «настроения»: сцена (4 источника света за стеклом), плотность и блики стекла, текст, лента акцента, статусы, цвет следа |
| Движок | `src/theme/engine.ts` | Тема × настройки → CSS-переменные на `:root`. Смена темы — плавным перетеканием окна (View Transitions); System следит за режимом Windows; фон окна Tauri подстраивается под тему |
| Состояние | `src/theme/AppearanceProvider.tsx` | Применяет сразу, сохраняет с задержкой 450 мс: localStorage (мгновенная первая отрисовка) + `config.json` (надёжная копия) |
| Токены | `src/styles/tokens.css` | Полный набор токенов с фирменной тёмной темой по умолчанию |
| Движение | `src/styles/motion.css`, `src/theme/motion.ts` | Сцена, Liquid Glass, переходы страниц, появление при прокрутке, микроанимации |
| Галерея | `src/pages/Appearance.tsx`, `src/styles/appearance.css` | Темы с живыми миниатюрами, персонализация, след |

Все компоненты берут цвета из токенов: `--ink` (линии; белые в тёмных темах, тёмно-синие в светлых), `--fill` (стекло; белое), `--spec` (блики; всегда белые), `--accent-1..3`, `--surface`, `--well`, `--ok/--warn/--bad`. Захардкоженные цвета переведены в токены скриптом по смыслу свойства (фон / линия / блик).

## Темы

Светлые: Liquid Glass Light, Pure White, Arctic Blue, Aurora, Pearl, Soft Lavender, Sky Glass.
Тёмные: Liquid Glass Dark, Midnight, Deep Ocean, Violet Night, Obsidian.
Режимы: System (Liquid Glass Light/Dark по режиму Windows), Custom (основа, две ленты, фон).

## Персонализация

Акцент, размытие, прозрачность панелей, стеклянные эффекты, свечение, градиенты, насыщенность, скругление, тени, скорость анимаций. Переключатели: Liquid Glass, преломление (SVG-линза `#lens` на кнопках питания и индикаторе меню), фоновые анимации, анимации интерфейса, уменьшенная анимация, сохранение настроек. «Вернуть по умолчанию».

## След за курсором

React Bits **SplashCursor** (WebGL2, жидкие чернила), исходник без изменений в `src/components/SplashCursor/`. Обёртка `src/components/CursorTrail.tsx`:

- слой лежит **за интерфейсом** — над фоном, под оболочкой окна; стеклянные панели размывают чернила;
- `pointer-events: none`, слушает только `pointermove/pointerdown` окна — клики, выделение и прокрутка не затрагиваются;
- цвета — лента акцента активной темы (или акцент, или радуга); в тёмных темах чернила светятся, в светлых окрашивают стекло;
- настройки: интенсивность, размер, длительность (скорость исчезновения), завихрения, свечение, всплеск по клику; при уменьшенной анимации завихрения и всплески приглушаются;
- симуляция спит, когда чернила погасли; качество `medium`; выключение освобождает WebGL-контекст.

## Производительность

Анимации фона — только `transform/translate/scale` на четырёх слоях; при скрытом окне анимации и чернила ставятся на паузу. Свет под курсором — один обработчик `pointermove` с ограничением до кадра. Миниатюры тем — без `backdrop-filter`. Отслеживание появления карточек — `IntersectionObserver`, один на страницу.
