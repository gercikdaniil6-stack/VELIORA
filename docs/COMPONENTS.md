# Компоненты VELIORA App 2.0: как устроены и откуда взяты

## Telegram-прокси (TgWsProxy 1.11.4)

- **Источник:** исходный код Flowseal/tg-ws-proxy (MIT), без изменений.
- **Почему пересборка:** официальный Windows-релиз — программа с иконкой в трее, она игнорирует `--host/--port/--secret`. Поэтому консольная точка входа `proxy.tg_ws_proxy:main` упакована PyInstaller 6.16.0 в один файл (`scripts/build-tgws.ps1`; сборка идёт во временной папке с отдельным виртуальным окружением).
- **Файл:** `src-tauri/components/tgws/TgWsProxy.exe`, SHA-256 записан в `components.json`.
- **Запуск:** `TgWsProxy.exe --host 127.0.0.1 --port 1443 --secret <32 hex> [--cfproxy-worker-domain <домен>] [-v]`, скрыто, внутри job object (процесс и его потомки завершаются вместе с VELIORA, даже при аварии).
- **Ссылка:** `tg://proxy?server=<хост>&port=<порт>&secret=dd<ключ>` — режим со случайным выравниванием пакетов, его выводит и сам прокси.
- **Проверено:** реальный обмен с Telegram (`req_pq_multi` → `resPQ`) через прокси, запущенный кнопкой в приложении: DC2 и DC4 напрямую по WebSocket (~55 мс), DC5 через Cloudflare (~1 с); неверный ключ отклоняется.

## Zapret (сборка Flowseal 1.10.4)

- **Источник:** официальный архив релиза `zapret-discord-youtube-1.10.4.zip` с GitHub. `npm run components` проверяет SHA-256 по контрольной сумме, которую публикует GitHub (`291af673…5f97b34`). `winws.exe` и `WinDivert64.sys` побайтно совпадают с файлами, которые поставляет Slipgate.
- **Рабочая копия:** при первом запуске с правами администратора сборка копируется в `%ProgramData%\VELIORA\zapret`. Права папки: SYSTEM и администраторы — полный доступ, пользователи — только чтение и запуск. Рядом хранятся заводские копии списков (`.originals`).
- **Запуск стратегии:** VELIORA читает команду `winws.exe` из `general*.bat` (склейка строк по `^`, кавычки, экранирование `^!` как в cmd), подставляет `%BIN%`, `%LISTS%`, порты игрового фильтра и выбранные фейки и запускает `winws.exe` напрямую, без `cmd` и `service.bat` (без сетевой проверки обновлений внутри bat-файлов). Перед запуском: проверка прав, проверка чужого `winws.exe` и GoodbyeDPI (VELIORA не завершает чужие процессы, а объясняет, что нужно выключить), проверка службы BFE, сброс регистрации WinDivert, если она указывает на удалённый файл, и включение TCP timestamps, как это делают скрипты Flowseal.
- **Игровой фильтр:** выкл / TCP и UDP / TCP / UDP, свои диапазоны портов. Выключенный фильтр подставляет порт `12`, как в скриптах Flowseal.
- **IPSet:** базовый (сети Telegram + ваши IP), полный (список Flowseal из `ipset-all.txt.backup`, 33 048 записей + ваши IP), все адреса (пустой файл). Файл `ipset-all.txt` пересобирается перед каждым запуском; ваши IP хранятся отдельно в `ipset-all-user.txt`.
- **Фейки:** `ACTIVE_DISCORD_UDP.bin` и `ACTIVE_GAME_UDP.bin` в аргументах заменяются выбранным образцом из `bin\`; файлы сборки не меняются.
- **Проверено:** `cargo test -- --ignored winws` запускает настоящий `winws.exe --dry-run` со всеми 22 стратегиями в 6 комбинациях (2 режима игрового фильтра × 3 режима IPSet): 132 из 132 — «command line parameters verified».

## Тест стратегий

1. Замер без обхода (две попытки на цель): YouTube, Discord, Google, Cloudflare, Telegram Web — HTTPS-запрос по новому соединению, без системного прокси. Отдельно отмечаются ошибки DNS и подменённого сертификата: их обход DPI не лечит.
2. Каждая стратегия: запуск winws, прогрев, повторный замер. Считается, сколько заблокированных целей открылось, что сломалось из работавшего и средняя задержка. «Работает» — открыто не меньше половины заблокированного и ничего не сломано.
3. Три лидера перепроверяются, результаты усредняются. «Лучшая» — максимальный балл; «наравне» — тот же балл и задержка в пределах 15 %.
4. Предупреждения: активный VPN-туннель, включённый системный прокси, сервисы, которые не открыла ни одна стратегия. Тест можно отменить; если Zapret был включён, после теста он запускается снова.

## Что не перенесено из Slipgate и почему

- **Списки сообщества, никнеймы, статистика онлайна** — работают через сервер авторов Slipgate. Подключать VELIORA к чужому серверу и отправлять ему данные пользователя нельзя. Импорт и экспорт `.txt` закрывают обмен списками вручную.
- **Обновление самого приложения из интерфейса** — у VELIORA пока нет публичного канала релизов. Обновления сборки Zapret — есть; о новой версии TgWsProxy приложение сообщает, а сам файл приходит с новой версией VELIORA (официальный Windows-файл не подходит, см. выше).
- **Английский интерфейс и светлая тема** — VELIORA сделана на русском, в фирменной тёмной Liquid Glass-гамме. Режим «Уменьшить прозрачность» остался.
- **Продолжение теста после перезапуска приложения** — отчёт сохраняется после каждой стратегии, но прерванный тест начинается заново.
