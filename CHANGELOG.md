# История версий

## 2.2.10 — Конфликты Zapret

- Диагностика проверяет процессы WinDivert и сведения о службах Windows. Неопознанные процессы требуют проверки пользователем.
- VELIORA может остановить проверенную стороннюю службу через Windows с разрешения пользователя. Разрешения можно отозвать в настройках.
- Добавлена ограниченная попытка восстановления собственного Zapret и отдельное сообщение для занятого фильтра WinDivert.

## 2.2.9 — Добавление сайта по ссылке

- Добавление сайта в одном поле. Каталог находит готовые профили вместе с их дополнительными адресами или создаёт правило для сайта.
- Если подходящие настройки нельзя применить, VELIORA предлагает открыть диагностику Zapret. Доступность проверяется отдельным прямым HTTPS-запросом.
- Название и выбор стратегии для существующих сайтов перенесены в дополнительные настройки. Импорт и экспорт списков TXT убраны из интерфейса.

## 2.2.8 — Объединённый каталог

- Убрали статистику с главной и остановили накопление её фоновых показателей. Журнал диагностики доступен в настройках.
- Готовые обходы и пользовательские сайты теперь в одном каталоге с поиском, фильтрами и предварительным просмотром адресов.
- Тяжёлые страницы и WebGL-эффект курсора загружаются по требованию. Журнал загружается только при открытии.

## 2.2.7 — Менеджер Zapret

- Главная и раздел «Статистика» показывают запуски, реальное время работы Zapret, результаты локальной диагностики и события.
- Каталог настраивает правила для популярных сервисов, «Мои сайты» принимает URL и домены, поддерживает импорт и экспорт TXT.
- Версии Zapret показывают даты из GitHub Releases. Проверенные архивы доступны для повторного переключения.
- Obsidian применяется по умолчанию при чистом запуске. Текущие настройки оформления сохраняются.
- Раздел системного прокси убран из главного окна. Telegram, базовые списки Zapret и диагностика Discord остаются доступны.

## 2.2.6 — подготовка

- Проверка обновлений VELIORA через GitHub при запуске и во время работы.
- Показ изменений и прогресса загрузки. Установка только после проверки подписи.

## 2.2.5 — кандидат на закрытое тестирование

- Обновлены зависимости SQLite и ZIP. Проверяются разрешённые адреса загрузки, размер архива и SHA-256 обновления Zapret.
- Запуск Zapret требует защищённой рабочей папки. Процессы запускаются только с контролем через группу Windows.
- Системный прокси меняется после сохранения точки восстановления. Ошибка восстановления сохраняет точку для повторной попытки.
- Локальный ключ Telegram защищается Windows DPAPI в настройках и резервной копии. Ссылки с ключами маскируются в новых записях журнала.
- Временная ошибка создания HTTPS-клиента каталога приводит к повторной попытке с растущей паузой. Сохранённые записи остаются доступны.
- Исправлено обрезание подписей кнопок в настройках. В каталоге добавлено предупреждение о сторонних прокси.

## 2.2.4

- Диагностика каталога сохраняет HTTP-статус, длительность, число ссылок и причину ошибки отдельно для каждого источника.
- Повторные ошибки увеличивают интервал до часа с учётом более длительного Retry-After. Пауза после успешной загрузки отображается отдельно.
- Запросы каталога используют актуальные параметры системного прокси или выбранный прямой маршрут. Сохранённые серверы проходят повторную проверку после перезапуска.

## 2.2.3

- Профили UDP для Discord и ручная проверка голоса и демонстрации с сохранением подтверждённого режима.
- Диагностика Discord разделяет HTTPS, тестовый обмен UDP и подтверждение трансляции со стороны зрителя.
- Проверка конфликтов учитывает winws2 и исключает только PID, которым управляет VELIORA. Запуск Zapret больше не меняет глобальные TCP timestamps.

## 2.2.2

- Два резервных источника каталога и отдельная пауза для каждого источника после ошибок.
- Каталог сохраняется при обрыве сети. Устаревшие записи отмечаются, а журнал показывает причину сбоя без ключей.
- Установщик включает библиотеки среды Visual C++, необходимые для проверки серверов.

## 2.2.1

- Каталог и локальный режим объединены в разделе Telegram. Кнопка на главной подбирает сервер и включает прокси. Повторное нажатие закрывает локальный порт и активные соединения.

## 2.2.0

- Вкладка Telegram Proxy с каталогом публичных серверов, фоновым обновлением и локальным каталогом SQLite.
- TCP и запрос к Telegram через TDLib измеряются отдельно. Рейтинг учитывает последние 12 проверок. В истории доступны 24 последних результата.
- Выбранный сервер перепроверяется перед передачей ссылки в Telegram Desktop. Автовыбор предлагает резервный сервер при последовательных сбоях.

## 2.1.0 — первый публичный релиз

- Оформление: 14 тем (7 светлых, 5 тёмных, System, Custom), Liquid Glass с бликами и преломлением, настройка цветов, прозрачности и скорости анимаций.
- Жидкий след за курсором за стеклянными панелями, с настройкой палитры, размера и интенсивности.
- Новые анимации интерфейса и заставка при запуске (отключается в настройках).
- Лицензии сторонних компонентов устанавливаются вместе с приложением.
- Сборка релиза без локальных путей машины сборки внутри exe.

## 2.0.0

- Telegram-прокси: локальный WebSocket-прокси на базе Flowseal/tg-ws-proxy 1.11.4, ссылка `tg://proxy` в один клик, поддержка своего Cloudflare Worker.
- Zapret 1.10.4 (Flowseal/zapret-discord-youtube): 22 стратегии, игровой фильтр, режимы IPSet, сменные фейки, очистка кеша Discord, установка версий сборки с проверкой SHA-256.
- Тест стратегий под конкретную сеть с перепроверкой лидеров.
- Редактор списков доменов и IP, импорт и экспорт, бэкап и заводской сброс.
- Диагностика «Почему может не работать?», журнал событий, трей с переключателями, автозапуск через Планировщик заданий.

## 1.0.0

- Менеджер системного прокси Windows: профили HTTP/SOCKS-серверов, правила обхода, проверка задержки, восстановление прежних настроек Windows.
