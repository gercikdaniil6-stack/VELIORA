# Безопасность

## Что делает приложение с правами администратора

VELIORA App запрашивает права администратора, потому что драйверу WinDivert (Zapret) они нужны для перехвата пакетов. С правами приложение:

- запускает `winws.exe` с выбранной стратегией и `TgWsProxy.exe`, внутри job object, чтобы процессы завершались вместе с приложением;
- копирует сборку Zapret в `%ProgramData%\VELIORA\zapret\` и выставляет права папки: полный доступ у SYSTEM и администраторов, у пользователей только чтение и запуск;
- при включённом автозапуске создаёт задачу в Планировщике заданий;
- меняет настройки системного прокси Windows только по вашей команде и восстанавливает прежние при отключении.

Чужие процессы приложение не завершает. Если найден другой обход DPI или конфликтующая программа, оно объясняет, что выключить.

## Данные

- Телеметрии нет. Сетевые запросы: GitHub API для проверки версий компонентов (отключается в настройках) и тест стратегий, который проверяет доступность нескольких публичных сайтов.
- Ключ Telegram-прокси генерируется случайно на каждом компьютере и хранится только в `%LOCALAPPDATA%\app.veliora.desktop\config.json`.
- Прокси слушает `127.0.0.1` по умолчанию. Если открыть его в локальную сеть, подключиться сможет любой, кто знает ключ.

## Проверка файлов

- SHA-256 установщика публикуется в описании каждого релиза.
- Версии и SHA-256 сторонних компонентов записаны в `src-tauri/components/components.json`. Сборка Zapret сверяется с контрольной суммой релиза на GitHub.
- Некоторые антивирусы реагируют на инструменты обхода DPI (winws, WinDivert). Результат VirusTotal для конкретной сборки указан в описании релиза.

## Как сообщить об уязвимости

Не публикуйте детали уязвимости в открытых Issues. Используйте приватное сообщение через вкладку **Security → Report a vulnerability** этого репозитория. Мы ответим и выпустим исправление как можно быстрее.
